تشغيل صفحة Calorie Profile في VS Code

1. فك ضغط الملف أولًا.
2. File > Open Folder ثم اختر مجلد calorie-profile-live-v4.
3. افتح profile.html من داخل هذا المجلد.
4. اضغط بالزر الأيمن داخل profile.html ثم Open with Live Server.
5. اضغط Ctrl + F5 مرة واحدة في المتصفح.

الملفات الثلاثة يجب أن تبقى معًا في نفس المجلد:
profile.html
profile-v4.css
profile-v4.js

الصفحة تربط النسخة الجديدة بهذه الأسماء تحديدًا.
لا تنسخ HTML وحده ولا تشغّل profile.html من المجلد القديم.
Edit Profile يُظهر حقل Username في Account Details.
تغيير Gender يحدّث الرمز فورًا، وSave Changes يحفظ التعديلات في معاينة الصفحة.
البيانات التجريبية تعود للقيم الأصلية بعد إعادة تحميل الصفحة.
الحفظ الدائم يحتاج ربط API كما هو موضح داخل PROFILE_CONFIG.
