# Calorie

Calorie is a web application designed to help users track their daily calorie and nutritional intake. The application allows users to manage their personal information, record meals, monitor calories and macronutrients, and view their nutrition history.

## Project Structure

* `Backend/` - Backend built with Node.js and Express.js.
* `Frontend/` - Frontend built with HTML, CSS, and JavaScript.

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB

The project is currently under development.
